# English-to-Arabic Neural Machine Translation (NMT) using Seq2Seq with Attention

An end-to-end Neural Machine Translation (NMT) system that translates English sentences into Arabic. The project implements a custom Deep Learning pipeline built from scratch using **PyTorch**, leveraging a **Bidirectional GRU Encoder** and a **Bahdanau-style Attention Mechanism** inside the Decoder.

The model was trained on a filtered subset of the **Opus100 dataset**, utilizing advanced optimization techniques to guarantee stable training, memory efficiency, and prevention of overfitting.

---

## 🌟 Key Features
- **Custom Tokenizer:** Trained a `SentencePiece` (Unigram) tokenizer from scratch with a vocabulary size of 9,000, optimized for Arabic morphology.
- **Advanced Architecture:** Bidirectional GRU Encoder to capture bidirectional context, coupled with a Bahdanau Attention Layer to align English source tokens with Arabic translations.
- **Smart Data Pipeline:** Sentences sorted by length during preprocessing to minimize padding, reducing GPU memory footprint and accelerating training speed by ~40%.
- **Robust Training Design:** Includes Mixed Precision Training (`torch.amp`), Label Smoothing (0.15) to alleviate overconfidence, Weight Decay (`AdamW`), and Learning Rate Decay on Plateau (`ReduceLROnPlateau`).
- **Overfitting Guard:** Implemented Early Stopping with a patience parameter to automatically save the most generalized model checkpoint.
- **Advanced Inference:** Supports **Beam Search Decoding** during the evaluation phase to yield highly contextualized translation hypotheses.

---

## 🏗️ Project Architecture & File Structure

The repository is modularly designed as follows:
- `data_preprocessing.py`: Handles dataset loading, cleaning, filtering (sentence lengths between 3 and 20 words), Tokenizer training, custom `Dataset`, and smart `DataLoader` creation.
- `model_seq2seq.py`: Contains the deep learning model classes (`Encoder`, `Attention`, `Decoder`, and the parent `Seq2Seq` wrapper).
- `training.py`: The core training loop utilizing gradient scaling, gradient clipping, Dynamic Teacher Forcing decay, and automated Google Drive checkpointing.
- `evaluation.py`: Evaluates the trained model utilizing Beam Search and computes the final **BLEU Score** using NLTK's Smoothing Function (Method 4).

## ⚙️ Hyperparameters

| Hyperparameter | Value | Description |
| :--- | :--- | :--- |
| **Vocabulary Size** | 9,000 | Piece size generated by SentencePiece |
| **Embedding Dim** | 128 | Vector dimension for word embeddings |
| **Hidden Dim** | 128 | Number of features in GRU hidden states |
| **Num Layers** | 2 | Stacked GRU layers in Encoder & Decoder |
| **Attention Dim** | 128 | Internal dimension for Bahdanau energy calculation |
| **Learning Rate** | 4e-4 | Managed dynamically by `ReduceLROnPlateau` |
| **Batch Size** | 32 | Optimal size balancing speed and GPU stability |
| **Dropout** | 0.5 | Applied to prevent overfitting in recurrent units |

## 📊 Training Logs & Convergence Insights

The model converged smoothly over **26 epochs** before being halted by the Early Stopping mechanism to guarantee generalization:
- **Starting Point (Epoch 1):** Train Loss: `7.18` | Val Loss: `7.01`
- **Optimal Checkpoint (Epoch 14):** Achieved Best Validation Loss: `6.6195`
- **Inference Progression:** The model successfully shifted from repetitive degenerate outputs (e.g., *"أنا، أنا، أنا"*) into capturing syntactic structures, connectives, and complex future-tense inflections (e.g., translating *"i've gotta run, so i'll leave you..."* into *"حسناً، سأ، لذا سأعطيك سوف اضطر للعمل"*).
